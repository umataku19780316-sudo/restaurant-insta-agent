# 飲食店向けInstagram集客キット

飲食店(カフェ・居酒屋・レストラン・バーなど)がInstagramを使った集客を「仕組み化」するためのデジタル商品です。ChatGPTやClaudeなどの生成AIにコピー&ペーストするだけで使える**プロンプト集**と、アカウント運用の抜け漏れを防ぐ**チェックリスト**をセットにしています。

## 想定ユーザー

- Instagram運用の担当者がいない、または兼任で手が回っていない個人経営〜小規模チェーンの飲食店オーナー・店長
- 「投稿ネタが尽きる」「キャプションを考える時間がない」「リールの作り方が分からない」「プロフィールを整える余裕がない」という悩みを抱えている方

## 使い方の全体像

1. ①のプロンプトで1ヶ月分の投稿ネタを一括生成
2. ②のプロンプトで各ネタのキャプション・ハッシュタグを生成
3. ③のプロンプトでリール投稿の台本(構成・テロップ・尺)を生成
4. ④のチェックリストでプロフィールと予約導線を点検・整備
5. ⑤のガイドを読んで全体の運用フローと販売ページ用の文章を確認
