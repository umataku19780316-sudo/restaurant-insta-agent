# ① ネタ出し自動化プロンプト

Instagram投稿の「ネタが思いつかない」を解消するためのプロンプトです。店舗の基本情報を入力するだけで、1ヶ月分(目安30本)の投稿ネタを、カテゴリ・フック文・狙いつきで一括生成します。

## 使い方

1. 下記の「入力シート」を埋める(コピーして使ってください)
2. 「プロンプト本文」に入力シートの内容を貼り付けて、ChatGPT / Claude / Geminiなど生成AIに投げる
3. 出力されたネタ一覧をそのまま投稿カレンダーに転記する
4. 各ネタを②のキャプション生成プロンプト、③のリール台本生成プロンプトに渡して仕上げる

## 入力シート(コピーして埋めてください)

```
- 店舗名:
- 業態(例:カフェ/居酒屋/焼肉/イタリアン/バーなど):
- 立地・最寄駅:
- 客単価:
- ターゲット客層(例:20代女性の友人グループ、家族連れ、一人飲み層など):
- お店の強み・こだわり(食材/調理法/内装/接客/店主のキャラクターなど):
- 今月のイベント・季節ネタ(新メニュー、記念日、季節の食材、地域イベントなど):
- 直近1ヶ月で投稿した内容(ネタ被り防止のため箇条書きで):
- 避けたいネタ・NGワード(あれば):
- 投稿本数の目安(例:週3本 → 月12本):
```

## プロンプト本文

```
あなたは飲食店のSNS集客を専門とするInstagramマーケティングコンサルタントです。
以下の店舗情報をもとに、Instagramのフィード投稿・リール投稿のネタを{投稿本数}本、
「ネタ被りなく」「来店動機に直結する形」で提案してください。

【店舗情報】
店舗名:{店舗名}
業態:{業態}
立地・最寄駅:{立地・最寄駅}
客単価:{客単価}
ターゲット客層:{ターゲット客層}
お店の強み・こだわり:{お店の強み・こだわり}
今月のイベント・季節ネタ:{今月のイベント・季節ネタ}
直近1ヶ月の投稿内容(被り防止用):{直近1ヶ月で投稿した内容}
NGワード・避けたいネタ:{避けたいネタ・NGワード}

【ネタ出しの観点(できるだけ幅広くカバーしてください)】
1. メニュー紹介(定番/新作/裏メニュー/期間限定)
2. 舞台裏・調理工程(仕込み、こだわりの製法、食材の仕入れ先)
3. お客様の声・利用シーン(記念日、女子会、接待、家族利用など)
4. スタッフ紹介・店主の人柄が伝わるもの
5. 季節・イベント・地域ネタ(祭り、天候、地元情報との掛け合わせ)
6. ハウツー・豆知識(美味しい食べ方、ペアリング、保存方法など)
7. ビフォーアフター・比較(内装リニューアル、盛り付けの変化など)
8. トレンド便乗(直近のInstagramで流行っている型に、自店のネタを当てはめる)
9. 予約・来店を後押しする情報(空席状況、混雑時間帯、予約方法の案内)

【出力形式】
表形式で、以下の列を必ず含めてください。
- No.
- カテゴリ(上記1〜9のいずれか)
- ネタ内容(具体的に。誰が見ても撮影・執筆イメージが湧く粒度で)
- フック文案(投稿の1枚目・冒頭で使う、目を引く一言)
- 投稿形式のおすすめ(フィード/リール/ストーリーズのいずれか、理由も一言)
- 狙い・期待効果(例:保存率アップ、来店予約への直結、ファン化など)

【制約】
- 直近1ヶ月の投稿内容と内容が重複しないようにしてください
- NGワード・避けたいネタは絶対に含めないでください
- 特定の日にちが分かるものは「◯月◯週目向け」のように投稿タイミングの目安も添えてください
- 実際にその店舗が写真・動画を撮れる前提で、具体的かつ実行可能な内容にしてください
```

## 出力例(抜粋イメージ)

| No. | カテゴリ | ネタ内容 | フック文案 | 投稿形式 | 狙い |
|---|---|---|---|---|---|
| 1 | メニュー紹介 | 秋の新作「きのこと栗の土鍋ご飯」の炊き上がり演出 | 「土鍋の蓋を開けた瞬間、湯気で顔が見えなくなる」 | リール | 保存・シェア率アップ、季節感訴求 |
| 2 | 舞台裏 | 毎朝仕入れる魚を大将が目利きする様子 | 「これが選ばれなかった魚、実は…」 | リール | 店主の人柄・信頼感の醸成 |
| 3 | お客様の声 | 誕生日サプライズ対応の様子(許可を得た実例) | 「サプライズ、成功しました」 | フィード | 記念日利用の来店動機喚起 |

## カスタマイズのヒント

- 業態別(カフェ/居酒屋/焼肉など)にNo.9「予約導線」の比重を調整すると効果的です
- 月初にまとめて実行し、週1回「直近の投稿内容」を更新して再実行すると、ネタ切れを防げます
- 出力後、②のキャプション生成プロンプトの「ネタ内容」欄にそのままコピーして使えます
