# ① ネタ出し自動化プロンプト

Instagram投稿の「ネタが思いつかない」を解消するためのプロンプトです。店舗の基本情報を入力するだけで、1ヶ月分(週2回×4週=8本)の投稿ネタを、撮り方・投稿文の書き出し・ハッシュタグ用キーワードまでセットで一括生成します。

## 使い方

1. 下記の「入力シート」を埋める(コピーして使ってください)
2. 「プロンプト本文」に入力シートの内容を貼り付けて、ChatGPT / Claude / Geminiなど生成AIに投げる
3. 出力されたネタ一覧をそのまま投稿カレンダーに転記する
4. 各ネタを②のキャプション生成プロンプト、③のリール台本生成プロンプトに渡して仕上げる

## 入力シート(コピーして埋めてください)

```
- 業態(例:イタリアン/カフェ/居酒屋/ラーメン店):
- 看板メニュー(例:自家製生パスタ、季節のスイーツ):
- 客層(例:20代女性中心、ファミリー層、サラリーマン):
- 現在の季節/直近のイベント(例:秋限定メニュー開始、忘年会シーズン):
- 店舗の強み/こだわり(例:地元食材使用、店主が○○出身):
- お店の雰囲気で伝えたいこと(例:隠れ家感、活気がある、家族経営の温かさ):
```

## プロンプト本文

```
# 役割
あなたは飲食店専用のSNS投稿ネタ出しアシスタントです。
入力された店舗情報をもとに、Instagram投稿ネタを1ヶ月分(週2回×4週=8本)提案してください。

# 入力してもらう情報(お客様が埋める欄)
- 業態: {業態}
- 看板メニュー: {看板メニュー}
- 客層: {客層}
- 現在の季節/直近のイベント: {現在の季節/直近のイベント}
- 店舗の強み/こだわり: {店舗の強み/こだわり}
- お店の雰囲気で伝えたいこと: {お店の雰囲気で伝えたいこと}

# 出力ルール
1週間ごとに2本、計8本のネタを提案する。以下5つの「型」をバランスよく組み合わせること:

- **裏側系**: 仕込み風景・食材へのこだわり・調理過程
- **メニュー訴求系**: 看板メニューの魅力を切り口を変えて紹介
- **お客様の声系**: 来店客の反応・リピーターエピソード(実例がなければ「投稿の型」だけ提示)
- **季節イベント系**: 直近の季節・イベントに絡めた投稿
- **来店動線系**: 予約方法・アクセス・営業時間などを自然に盛り込む投稿

# 各ネタの出力フォーマット
## 週◯・ネタ◯:【型】タイトル
- **投稿内容の概要**: (2〜3行)
- **おすすめの撮り方/構図**: (写真or動画のポイント)
- **投稿文の書き出し例**: (1〜2文、そのまま使える文体で)
- **入れるべき要素**: (ハッシュタグに使うキーワード3〜5個、地域名・料理ジャンル・季節ワードを含める)

# 注意事項
- 汎用的な内容(「美味しい料理です」等)は避け、入力された店舗情報を必ず反映させる
- 予約・来店につながる一言(来店動線)を8本のうち最低2本には自然に含める
- 専門用語は使わず、飲食店オーナーがそのまま実行できる粒度にする
```

## 出力例(抜粋イメージ)

以下は「業態:イタリアン/看板メニュー:自家製生パスタ/客層:20代女性中心/季節:秋限定メニュー開始/強み:地元食材使用・店主がイタリア修業経験あり/雰囲気:隠れ家感」を入力した場合の出力イメージです。

```
## 週1・ネタ1:【メニュー訴求系】秋の新作パスタ、麺から手作りの理由
- 投稿内容の概要: 自家製生パスタを打つ工程から、秋限定ソース(きのこクリーム)で
  仕上げるまでの一連の流れを見せる。生地のコシ・もちもち感が伝わるカットを中心に。
- おすすめの撮り方/構図: 麺を伸ばす瞬間を真上から、仕上げは湯気が立つ状態で斜め上から
- 投稿文の書き出し例: 「生地から手で伸ばす。だから、このコシが出るんです。」
- 入れるべき要素: #自家製パスタ #生パスタ #秋の味覚 #隠れ家イタリアン #(エリア名)ディナー

## 週1・ネタ2:【来店動線系】少人数の隠れ家で、女子会の予約が増えている理由
- 投稿内容の概要: 店内の落ち着いた照明・個室感のある席を紹介しつつ、
  「少人数向けの予約が取りやすい時間帯」を自然に案内する。
- おすすめの撮り方/構図: 店内の席全体が入る引きの構図+料理が並んだテーブルのアップ
- 投稿文の書き出し例: 「実は、平日の19時台が一番ゆっくりできる時間なんです。」
- 入れるべき要素: #隠れ家イタリアン #女子会 #(エリア名)ディナー #予約はプロフィールから #秋の味覚
```

## カスタマイズのヒント

- 8本という本数は「週2回投稿」を想定した目安です。投稿頻度が週3回以上の店舗は、入力シートの下に「投稿本数の目安」を追記してプロンプト内の本数指定を書き換えてください
- 「お客様の声系」は実例が無い場合、AIが「投稿の型」だけを提示する設計になっています。実際の来店客エピソードが集まったら、その都度差し替えてリアリティを高めてください
- 出力後、②のキャプション生成プロンプトの「ネタ内容」欄に「投稿内容の概要」をそのままコピーして使えます
- ③のリール台本生成プロンプトに渡す際は、「おすすめの撮り方/構図」をヒントとして活用すると、より一貫性のある仕上がりになります
