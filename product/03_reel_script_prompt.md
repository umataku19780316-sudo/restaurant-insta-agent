# ③ リール台本生成プロンプト

Instagramリールは「何を撮ればいいか分からない」「編集が大変」という声が多い投稿形式です。このプロンプトは、①のネタを入力するだけで撮影用の「台本(構成・カット割り・テロップ・尺)」を自動生成し、撮影のハードルを下げます。①と同じ入力項目を使う設計のため、①の出力(投稿内容の概要・撮り方/構図)をそのまま貼り付けて使えます。

## 使い方

1. ①で生成したネタから、リール向きのものを選ぶ(型・投稿内容の概要・撮り方/構図をコピーしておく)
2. 「入力シート」を埋める(業態・看板メニューなどは①と同じ内容でOK)
3. 「プロンプト本文」に貼り付けて生成AIに投げる
4. 出力された台本をもとに、スマホ1台で撮影・編集する

## 入力シート

```
- 業態(例:イタリアン/カフェ/居酒屋/ラーメン店):
- 看板メニュー(例:自家製生パスタ、季節のスイーツ):
- 客層(例:20代女性中心、ファミリー層、サラリーマン):
- 投稿の型(①の出力からコピー。裏側系/メニュー訴求系/お客様の声系/季節イベント系/来店動線系):
- 投稿内容の概要(①の出力からコピー):
- おすすめの撮り方/構図(①の出力からコピー。あれば):
- 尺の目安(15秒/30秒/60秒):
- 撮影可能な場所・タイミング(例:開店前の仕込み中、ランチのピークタイム、閉店後の店内 など):
- 出演者(店主/スタッフ/顔出しNGか など):
- 使いたい・流行っている音源やトレンドの型(あれば):
- CTA(最後に促したい行動):
```

## プロンプト本文

```
# 役割
あなたは飲食店専用のショート動画(Instagramリール)構成作家です。
入力された店舗情報と投稿ネタをもとに、撮影・編集がしやすい形でリールの台本を作成してください。

# 入力してもらう情報(お客様が埋める欄)
- 業態: {業態}
- 看板メニュー: {看板メニュー}
- 客層: {客層}
- 投稿の型: {投稿の型}
- 投稿内容の概要: {投稿内容の概要}
- おすすめの撮り方/構図: {おすすめの撮り方/構図}
- 尺の目安: {尺の目安}
- 撮影可能な場所・タイミング: {撮影可能な場所・タイミング}
- 出演者: {出演者}
- トレンドの型・音源: {使いたい・流行っている音源やトレンドの型}
- CTA: {CTA}

# 出力ルール
台本は以下の4パートで構成する。
1. フック(0〜3秒):見た瞬間に「え、何これ」と思わせる映像・テロップ。結論や最も映える瞬間を先出しする
2. 展開(構成の中盤):課題提起→解決、意外性→種明かし、工程の積み上げ、のいずれかの型で飽きさせない
3. クライマックス:最も見せたい瞬間(盛り付け完成、実食、驚きの反応など)
4. CTA(ラスト2〜3秒):指定されたCTAを、テロップと口頭(字幕)の両方で自然に提示する

「おすすめの撮り方/構図」が入力されている場合は、そのカットを冒頭または中核カットとして必ず活かすこと。

# 出力フォーマット
表形式で、以下の列を含めること。
- カット番号
- 秒数の目安
- 画(カメラアングル・被写体・動きの指示。スマホ1台/三脚なしでも撮影できる指示にする)
- テロップ文言
- 音・BGMの使い方の指示(トレンド音源がある場合は合わせ方の目安も)
- 補足(撮影の注意点、NG例など)

表の後に、以下も出力する。
- キャプション案(1〜2行、リール本編の説明文)
- サムネイル(カバー画像)に使うべき瞬間の指定
- 撮影前チェックリスト(照明、音、清掃状態など3〜5項目)

# 注意事項
- 出演者がスタッフのみで顔出しNGの場合は、手元・調理工程・盛り付けなど「顔が映らない画」で構成する
- 実際に飲食店の従業員が、特別な機材なしで撮影・編集できる難易度にする
- 尺の目安を超えないよう、カットごとの秒数を調整する
- 投稿内容の概要・投稿の型を必ず反映させ、汎用的な演出は避ける
```

## 出力例(抜粋イメージ、尺30秒の場合)

①の出力例(業態:イタリアン/看板メニュー:自家製生パスタ/週1・ネタ1:秋の新作パスタ、撮り方:麺を伸ばす瞬間を真上から)を入力した場合のイメージです。

| カット | 秒数 | 画 | テロップ | 音・BGM | 補足 |
|---|---|---|---|---|---|
| 1 | 0-3秒 | 生地を伸ばす手元を真上から | 「生地から、手で伸ばす。」 | トレンド音源のサビ頭に合わせる | 生地の弾力が伝わるようゆっくり伸ばす |
| 2 | 4-12秒 | きのこクリームソースを絡める鍋元のアップ | 「秋限定、きのこクリーム」 | BGM継続 | 湯気がしっかり立つタイミングで撮影 |
| 3 | 13-22秒 | 盛り付け完了、器を回して仕上げる | 「1皿にこの季節を詰め込んだ」 | BGM継続、盛り付け完了で一瞬無音にすると余韻が出る | 器の縁を拭いてから撮影 |
| 4 | 23-30秒 | 実食(表情はスタッフの手元のみでもOK) | 「気になった方はプロフィールから予約を」 | BGMフェードアウト | CTAはテロップと字幕の両方に表示 |

## カスタマイズのヒント

- 「トレンドの型」を空欄にした場合でも、AIが定番の型(Before/After、カウントダウン、POV、ASMR系など)から提案してくれます
- 週1本からで十分です。まずは①のネタ出しでリール向きのものを2〜3本ストックし、撮り貯めしておくと運用が安定します
- 撮影後は②のプロンプトで、リール用のキャプション・ハッシュタグも合わせて生成してください
- ①の「投稿の型」が裏側系・メニュー訴求系のネタは特にリール向きです。優先的にこのプロンプトに回すと効果的です
