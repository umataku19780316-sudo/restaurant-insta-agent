# ② キャプション&ハッシュタグ生成プロンプト

①で出したネタをもとに、投稿用のキャプション(本文)とハッシュタグを自動生成するプロンプトです。「エンゲージメント重視」「予約直結」「ブランディング」の3パターンを一度に出力し、投稿の目的に応じて選べるようにしています。

## 使い方

1. ①で生成したネタから1つ選ぶ
2. 「入力シート」を埋める
3. 「プロンプト本文」に貼り付けて生成AIに投げる
4. 出力された3パターンから、投稿目的に合うものを選ぶ、または組み合わせて調整する

## 入力シート

```
- 店舗名:
- ネタ内容(①の出力からコピー):
- 投稿形式(フィード/リール/ストーリーズ):
- 写真・動画の内容(具体的に。何が写っているか):
- トーン&マナー(例:親しみやすい/上品・落ち着いた/元気でポップ など):
- CTA(投稿の最後で促したい行動。例:プロフィールのリンクから予約/コメントで質問受付/保存を促す など):
- 一人称・語尾の指定(例:「〜です」敬語、店主の一人称語り、スタッフ視点 など):
```

## プロンプト本文

```
あなたは飲食店のInstagram運用を専門とするコピーライターです。
以下の情報をもとに、Instagram投稿用のキャプションとハッシュタグを作成してください。

【投稿情報】
店舗名:{店舗名}
ネタ内容:{ネタ内容}
投稿形式:{投稿形式}
写真・動画の内容:{写真・動画の内容}
トーン&マナー:{トーン&マナー}
CTA:{CTA}
一人称・語尾:{一人称・語尾}

【キャプションの構成ルール】
1行目:スクロールを止めるフック文(絵文字は控えめに1〜2個まで)
2〜4行目:本文(ネタの魅力を具体的に。数字・五感表現・ストーリーを盛り込む)
5行目:CTA(指定されたCTAを自然な文章に落とし込む)
最終行:ハッシュタグ(本文とは1行空けて記載)

【出力パターン】
以下の3パターンをそれぞれ作成してください。

パターンA:エンゲージメント重視型
→ 保存・いいね・コメントを誘発する問いかけや共感を狙う

パターンB:予約直結型
→ 来店・予約への行動喚起を前面に出す

パターンC:ブランディング型
→ 店主・お店の世界観やこだわりを丁寧に伝える

【ハッシュタグのルール】
各パターンにつき合計25〜30個、以下の内訳でバランスよく作成してください。
- ビッグワード(投稿数10万件以上、例:#グルメ #カフェ巡り):3〜5個
- ミドルワード(投稿数1万〜10万件、例:業態+エリア名の組み合わせ):8〜10個
- スモールワード(投稿数1万件未満、例:店舗名、地域名+業態の細かい組み合わせ):10〜12個
- 店舗独自タグ(例:#店舗名 #店舗名グルメ など、指名検索・ファン化用):2〜3個

【制約】
- キャプションは1行が長くなりすぎないよう、こまめに改行してください
- 絵文字は多用せず、トーン&マナーに沿って最小限にしてください
- ハッシュタグは実際にInstagramで使われていそうな自然な単語にしてください
- 誇大表現・薬機法や景品表示法に抵触しそうな表現(効果を保証する表現など)は避けてください
```

## 出力例(抜粋イメージ)

```
【パターンB:予約直結型】

土鍋の蓋を開けた瞬間、湯気で顔が見えなくなるくらい。🍚

今年もこの季節がやってきました。
契約農家から届いた栗と、朝採れきのこを贅沢に炊き込んだ
秋限定の土鍋ご飯、本日から解禁です。

数量限定でご用意しているため、
ご予約はプロフィールのリンクからどうぞ。

#土鍋ご飯 #秋グルメ #きのこ料理 #栗ご飯 ...(以下26個)
```

## カスタマイズのヒント

- 週の投稿本数のうち、パターンBの比率を1〜2割程度にすると「宣伝っぽさ」を抑えつつ予約導線を確保できます
- 店舗独自タグは毎回固定にすることで、ファンが過去投稿・UGCを見返せるようになります
- ハッシュタグは3ヶ月に1回程度、実際の投稿インサイト(保存数・リーチ数)を見ながら入れ替えることをおすすめします
