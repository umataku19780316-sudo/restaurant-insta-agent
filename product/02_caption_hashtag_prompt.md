# ② キャプション&ハッシュタグ生成プロンプト

①で出したネタをもとに、投稿用のキャプション(本文)とハッシュタグを自動生成するプロンプトです。「エンゲージメント重視」「予約直結」「ブランディング」の3パターンを一度に出力し、投稿の目的に応じて選べるようにしています。①と同じ入力項目(業態・看板メニュー・客層など)を使う設計のため、①の出力をそのまま貼り付けて使えます。

## 使い方

1. ①で生成したネタから1つ選ぶ(型・投稿内容の概要をコピーしておく)
2. 「入力シート」を埋める(業態・看板メニューなどは①と同じ内容でOK)
3. 「プロンプト本文」に貼り付けて生成AIに投げる
4. 出力された3パターンから、投稿目的に合うものを選ぶ、または組み合わせて調整する

## 入力シート

```
- 業態(例:イタリアン/カフェ/居酒屋/ラーメン店):
- 看板メニュー(例:自家製生パスタ、季節のスイーツ):
- 客層(例:20代女性中心、ファミリー層、サラリーマン):
- お店の雰囲気で伝えたいこと(例:隠れ家感、活気がある、家族経営の温かさ):
- 投稿の型(①の出力からコピー。裏側系/メニュー訴求系/お客様の声系/季節イベント系/来店動線系):
- 投稿内容の概要(①の出力からコピー):
- 投稿形式(フィード/リール/ストーリーズ):
- 写真・動画の内容(具体的に。何が写っているか):
- CTA(投稿の最後で促したい行動。例:プロフィールのリンクから予約/コメントで質問受付/保存を促す など):
```

## プロンプト本文

```
# 役割
あなたは飲食店専用のSNSキャプション&ハッシュタグ作成アシスタントです。
入力された店舗情報と投稿ネタをもとに、Instagram投稿用のキャプションとハッシュタグを
3パターン作成してください。

# 入力してもらう情報(お客様が埋める欄)
- 業態: {業態}
- 看板メニュー: {看板メニュー}
- 客層: {客層}
- お店の雰囲気で伝えたいこと: {お店の雰囲気で伝えたいこと}
- 投稿の型: {投稿の型}
- 投稿内容の概要: {投稿内容の概要}
- 投稿形式: {投稿形式}
- 写真・動画の内容: {写真・動画の内容}
- CTA: {CTA}

# 出力ルール
以下の3パターンをそれぞれ作成する。

- **パターンA:エンゲージメント重視型** — 保存・いいね・コメントを誘発する問いかけや共感を狙う
- **パターンB:予約直結型** — 来店・予約への行動喚起を前面に出す
- **パターンC:ブランディング型** — 客層・雰囲気に合わせ、店主・お店の世界観やこだわりを丁寧に伝える

キャプションの構成は「フック文(1行、スクロールを止める)→本文(2〜4行、五感表現やストーリーを盛り込む)→CTA(1行)」とする。
ハッシュタグは各パターンにつき合計25〜30個、以下の内訳でバランスよく作成する。
- ビッグワード(投稿数10万件以上、例:#グルメ #カフェ巡り):3〜5個
- ミドルワード(投稿数1万〜10万件、例:業態+エリア名の組み合わせ):8〜10個
- スモールワード(投稿数1万件未満、例:地域名+業態の細かい組み合わせ):10〜12個
- 店舗独自タグ(指名検索・ファン化用):2〜3個

# 各パターンの出力フォーマット

- **キャプション**: (改行を含め、そのまま投稿できる形で)
- **ハッシュタグ**: (25〜30個、スペース区切り)

## パターンB:予約直結型
- **キャプション**:
- **ハッシュタグ**:

## パターンC:ブランディング型
- **キャプション**:
- **ハッシュタグ**:

# 注意事項
- 投稿内容の概要・投稿の型を必ず反映させ、汎用的な表現は避ける
- 絵文字は多用せず、お店の雰囲気に合わせて最小限にする
- ハッシュタグは実際にInstagramで使われていそうな自然な単語にする
- 誇大表現・薬機法や景品表示法に抵触しそうな表現(効果を保証する表現など)は避ける
- 専門用語を使わず、飲食店オーナーがそのまま投稿できる文章にする
```

## 出力例(抜粋イメージ)

①の出力例(業態:イタリアン/看板メニュー:自家製生パスタ/週1・ネタ1:秋の新作パスタ)を入力した場合のイメージです。

```
## パターンB:予約直結型
- キャプション:
  生地から手で伸ばす。だから、このコシが出るんです。

  秋限定、きのこクリームの自家製生パスタが解禁になりました。
  地元農家から届いた今朝収穫のきのこを、たっぷり練り込んでいます。

  数量限定のためご予約はプロフィールのリンクからどうぞ。

- ハッシュタグ:
  #自家製パスタ #生パスタ #秋の味覚 #隠れ家イタリアン #(エリア名)ディナー
  #(エリア名)グルメ #きのこパスタ #女子会 #記念日ディナー #イタリアン好きな人と繋がりたい
  ...(以下20個)
```

## カスタマイズのヒント

- 週の投稿本数のうち、パターンBの比率を1〜2割程度にすると「宣伝っぽさ」を抑えつつ予約導線を確保できます
- 店舗独自タグは毎回固定にすることで、ファンが過去投稿・UGCを見返せるようになります
- ハッシュタグは3ヶ月に1回程度、実際の投稿インサイト(保存数・リーチ数)を見ながら入れ替えることをおすすめします
- ①の「投稿の型」ごとにパターンの使用比率を変えるのもおすすめです(例:来店動線系の週は必ずパターンBを採用する)
