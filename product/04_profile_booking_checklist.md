# ④ プロフィール&予約導線チェックリスト

どれだけ良い投稿をしても、プロフィールや予約導線が整っていなければ「フォローされない」「予約に繋がらない」という機会損失が発生します。このチェックリストは、Instagramプロフィールと予約導線を一通り点検・整備するためのものです。月1回の見直しにも活用してください。

## A. プロフィール基本情報

- [ ] アカウント名(name欄)に、店舗名+検索されやすいキーワード(業態・エリア名)を含めている(例:「◯◯ | 渋谷 個室居酒屋」)
- [ ] ユーザーネーム(@id)がシンプルで覚えやすい・打ちやすい(店舗名と一致 or 近い)
- [ ] プロフィール写真が、遠目でも視認できるロゴまたは店舗を象徴する画像になっている
- [ ] 業種(飲食店カテゴリ)が正しく設定されている
- [ ] 連絡先ボタン(電話・メール・住所)が設定・最新の情報になっている

## B. プロフィール文(bio)

- [ ] 1行目で「何屋か」「どこにあるか」が一目で分かる
- [ ] 営業時間・定休日・客単価など、来店判断に必要な情報が簡潔に記載されている
- [ ] お店の強み・こだわりが一言で伝わるフレーズが入っている
- [ ] 絵文字を使い、情報を区切って視認性を高めている(詰め込みすぎない)
- [ ] 予約方法への導線(「予約はこちら↓」など)が明記されている
- [ ] 改行や記号を使い、5行以内で読みやすくまとまっている

### プロフィール文テンプレート例

```
◯◯(店舗名)|渋谷 個室居酒屋
🐟 毎朝仕入れる旬の鮮魚が自慢
🏮 記念日・接待に使える個室完備
🕕 17:00-24:00(日祝休)
📍渋谷駅徒歩5分
👇ご予約はこちらから
```

## C. リンク設定

- [ ] プロフィールのリンク欄(リンクインバイオ)に、予約ページ・LINE公式・Googleマップなど必要なリンクを設置している
- [ ] リンクが1つしか設置できない場合、複数リンクをまとめられるツール(リンクまとめページなど)を使っている
- [ ] 予約リンクをタップしてから、実際に予約が完了するまでの導線が3タップ以内になっている
- [ ] Googleマップのリンク先が正しい店舗情報(移転していないか等)を指している
- [ ] LINE公式アカウントがある場合、友だち追加までの導線が分かりやすい

## D. ハイライト(ストーリーズハイライト)

- [ ] 「メニュー」「アクセス」「お客様の声」「予約方法」など、来店判断に必要なカテゴリでハイライトを整理している
- [ ] ハイライトのカバー画像が統一されたデザイン(色・テイスト)になっている
- [ ] 各ハイライトの内容が最新の情報に更新されている(古いキャンペーン情報などが残っていないか)
- [ ] ハイライトの並び順が、来店検討者が見る優先度順になっている(例:メニュー→アクセス→予約方法)

## E. フィード投稿の一貫性(トンマナ)

- [ ] プロフィールを開いたときに見える直近9〜12投稿の色味・雰囲気に統一感がある
- [ ] 料理写真の明るさ・角度・背景のトーンが揃っている
- [ ] フィード全体で「メニュー」「雰囲気」「人」のバランスが取れている(メニューだけに偏っていないか)
- [ ] ピン留め投稿(固定表示)を使い、予約導線や代表メニューを一番上に表示している

## F. 投稿運用・エンゲージメント

- [ ] 投稿頻度が決まっている(例:フィード週2〜3本、リール週1本、ストーリーズ毎日)
- [ ] コメント・DMへの返信ルール(誰が・いつまでに返すか)が決まっている
- [ ] ストーリーズで質問スタンプ・投票スタンプなどを使い、フォロワーとの接点を作れている
- [ ] お客様が投稿・タグ付けしてくれた投稿(UGC)を、ストーリーズでリポストする習慣がある
- [ ] UGC活用について、事前にお客様への許可取りルールが決まっている

## G. インサイト(分析)の確認項目

- [ ] 月1回、フォロワー数の推移を確認している
- [ ] 投稿ごとの「保存数」「リーチ数」「プロフィールへのアクセス数」を確認し、反応の良かった投稿の傾向を把握している
- [ ] プロフィールへのアクセスから「外部リンクのタップ数」への遷移率を確認している
- [ ] リンクのタップから実際の予約数・来店数を(可能な範囲で)追跡できる仕組みがある(例:予約時に「Instagramを見た」と一言添えてもらう、専用クーポンコードなど)

## 運用のヒント

- まずはA〜Dの「土台」を整えることを最優先にしてください。ここが整っていないと、どれだけ良い投稿をしても機会損失が発生します
- E〜Gは継続的な改善項目です。月1回、このチェックリストを見返す運用をおすすめします
- ①〜③のプロンプトで投稿を仕組み化しつつ、このチェックリストで「入口(プロフィール)」と「出口(予約導線)」を定期的に点検することで、フォロワー増加が来店・予約に繋がりやすくなります
